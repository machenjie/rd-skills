# Starter Repo

## Stack

Python standard library. No network, package installation, model execution, or persistent storage is needed.

## Initial State

`commerce_saas.py` exposes the required function names but returns incomplete optimistic defaults. The starter is expected to fail the real assertions.

## Files

- `commerce_saas.py` is the implementation surface.
- `setup.sh` invokes the existing repository benchmark harness.
- The case-level `task.md` defines the records and outputs.

## Constraints

Implement only the bounded validation contract. Keep external effects absent and inputs unchanged. Do not infer runtime guarantees from fixture success.
