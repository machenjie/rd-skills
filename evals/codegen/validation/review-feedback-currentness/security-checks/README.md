# Security Checks

## Threat Surface

Feedback and authority are supplied records. The adapter performs no file, network, or external-thread action.

## Required Checks

Deny each ungranted effect separately. Preserve Review and Analysis read-only boundaries. Reject stale or mismatched evidence before accepting an edit.

## Rejection Cases

A valid defect or completed fix must not authorize reply, resolution, or rereview. The fixture does not authenticate a provider or replace its actual authorization checks.
