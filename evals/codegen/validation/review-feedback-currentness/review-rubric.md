# Review Rubric

## Passing Standard

Use current code and observed boundary results to decide feedback. Preserve distinct dispositions and separately granted actions.

## Scoring

Assess currentness, anchor binding, semantic validation, duplicate/conflict treatment, plan completeness, and separate authority boundaries.

## Automatic Failure Conditions

Rejecting unchanged reverified feedback solely for an old comment commit fails. Accepting stale proof, merging contradictory claims, or inferring external authority from a code fix also fails.

## Reviewer Notes

All effects are records. Deterministic quantity probes do not establish general code-review judgment, real repository history, provider permissions, or successful external communication.
