# Security Checks

## Threat Surface

This bounded fixture uses local records and fake collaborators. It has no live credentials, network effects, or production authority.

## Required Checks

Preserve input identity and supplied boundaries while rejecting invalid or contradictory states. This case neither generates load nor proves real latency, provider billing, GPU capacity, production quality, or model performance.

## Rejection Cases

Discarding unsent arrivals or measuring latency only after actual start. Approving higher throughput despite violated quality, tail-latency, or cost constraints. These correctness controls are not a comprehensive security assessment.
