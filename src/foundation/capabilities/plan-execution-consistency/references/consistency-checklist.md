# Plan and Execution Consistency Checklist

- Compare planned scope with the actual changed files.
- When an actual path is unplanned or an accepted planned path is omitted, explain the discrepancy.
- Map each behavior change to acceptance and post-edit validation.
- For the actual changed-path set, record its relation to the accepted plan and type-appropriate review or deterministic provenance/validation coverage.
- Confirm repair is followed by fresh affected validation. Require re-review only for a new material question needing independent judgment or an unresolved required review.
- Reconcile documentation, generated artifacts, migrations, and rollback.
- Return unverified scope and residual risk without creating internal state.
