# State Semantics Benchmark Anchors

Use this benchmark-pattern Reference only for the named state-semantics-benchmark-anchors decision.

## Benchmark Anchors

- Nielsen and XState make visible status, prevention, recovery, and explicit finite transitions useful for exposing impossible combinations and user actions.
- TanStack Query and SWR separate data availability from request progress, stale data, background refresh, pause, retry, validation, and error.
- Remix navigation and fetcher states distinguish idle, submitting, and loading across form submission and page loading.
- Select skeletons or action-level progress from layout stability, duration, interaction, and accessibility needs.

Use these as calibration evidence, not as a fixed state catalog. Return compared anchors and the selected semantic approach.
