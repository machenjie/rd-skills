# Working Context Selection Checklist

Use this checklist for one current decision, including resumed work, not for downstream transfer.

- Record source identity, freshness basis, and decision use for included facts and artifacts.
- Include Layer 3 Skill or Reference material only when it changes a named distinction in the decision.
- Exclude irrelevant, stale, and redundant context; record omissions that could change the result.
- Refresh the selection when a material state change invalidates an included item's freshness or decision use.
- When the context budget forces a choice, state the context-budget tradeoff, displaced evidence, and residual uncertainty.
- Return selected context, excluded context, refresh triggers, omissions, uncertainty, and residual risk.

## Resuming Interrupted Work

Reconstruct only what the next decision needs from available conversation and
artifacts: the current goal and constraints, changes already saved, unfinished
parts, the last confirmed state and checks, operations with unknown outcomes,
and the next action. An attempted operation is not a confirmed result; retain
that distinction when earlier context was compressed or a tool response was lost.

Re-read the affected current files and diff, then obtain necessary current Host
or external-operation status through the authorized owner. Compare them with the
last confirmed state before treating earlier validation as current. Keep other
contributors' changes and unresolved contradictions visible.

Resolve an unknown outcome before repeating a consequential action. For example,
a lost publish response requires checking the existing destination/job status;
it does not justify publishing a second time. If available evidence cannot settle
the outcome, preserve the uncertainty and request only the missing decision or
status needed by the authorized execution owner. Independent work may continue.

Use existing Host context and artifacts; do not create a checkpoint store or
background process. This Reference selects evidence and grants no additional
execution, external-read, or downstream-transfer authority to any Profile.
