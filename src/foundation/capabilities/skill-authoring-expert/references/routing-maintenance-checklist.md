# Routing Maintenance

Use only while authoring or independently auditing rd-skills routing assets. This internal Reference does not create a Runtime route or a Professional review owner.

## Authority And Inputs

- Treat the source registries and control-plane router as routing authority; generated selectors, catalogs, manifests, and reports are consumers.
- Name the changed route, its primary owner, supported profiles, review requirement, candidate modifiers, trigger, anti-trigger, and affected fixtures before editing.
- Inspect adjacent owners and the smallest positive, negative, and conflict cases that can distinguish the intended mapping.

## Contract Checks

- Keep each ordinary task on one deterministic primary Professional owner and reject ambiguous owner matches.
- Keep internal authoring validation out of the ordinary Professional catalog and Runtime top-level discovery surface.
- Require every candidate modifier to have a concrete decision problem, positive signal, anti-trigger, authorized owner edge, and built Reference when selected.
- Keep task-side and review-side modifier selection independent.
- Never copy task-side modifier selection into review-side selection.
- Confirm each registered Skill, route target, and selected Reference exists in the source graph and in the intended generated delivery surface.
- Update or remove every fixture, validator branch, context-budget expectation, and build assertion that consumes a changed route identity.

## Validation And Closure

1. Run registry, routing, Reference-content, and link validators against the final source edit.
2. Run the smallest positive, anti-route, owner-conflict, selector, context-budget, and build-inventory tests affected by the mapping.
3. Inspect a fresh temporary Runtime build to prove internal authoring capability is not top-level and the removed route is undiscoverable.
4. Report each former consumer as migrated, removed, regenerated, or not applicable; retain unknown external consumers as a proof limit.

Stop when two plausible owners remain, a generated projection cannot be traced to source, or a Runtime build still exposes an internal route.
