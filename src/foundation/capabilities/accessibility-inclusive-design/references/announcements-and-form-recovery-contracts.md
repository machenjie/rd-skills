# Announcements and Form Recovery Contracts

Use this Reference only for the named announcements-and-form-recovery-contracts decision.

## Decision Rules

- Announce consequential loading, completion, error, validation, and changed-state meaning once without stealing focus or repeating noise.
- Bind labels, instructions, required state, field association, error summary, and preserved input so users can locate, understand, correct, and resubmit invalid input.
- Select status urgency from current consequence and recovery; automation alone does not prove announcement timing or form usability.
- WCAG 2.2 supplies status-message and error criteria, while repository and product authority determine required behavior.
