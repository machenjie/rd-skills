# Visual Adaptation and Direct Manipulation Contracts

Use this Reference only for the named visual-adaptation-and-direct-manipulation-contracts decision.

## Decision Rules

- Keep information independent of color and preserve text and non-text contrast under supported themes with shape, text, position, or programmatic meaning.
- Support zoom, text scaling, reflow, localization, orientation, high contrast, and reduced motion without hiding content or controls.
- Give touch, drag, swipe, pointer, precision, and motion-operated outcomes an equivalent non-drag or non-precision path with an adequate target.
- WCAG 2.2 covers contrast, color, motion, target size, dragging alternatives, and reflow; platform support still requires current evidence.

Reject removal of visible focus, error text, or non-color cues because a mouse path works. Return the selected presentation and input alternatives with proof limits.
