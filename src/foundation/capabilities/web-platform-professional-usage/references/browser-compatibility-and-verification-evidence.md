# Browser Compatibility and Verification Evidence

Use this evidence-pattern Reference only for the named browser-compatibility-and-verification-evidence decision.

## Evidence Contract

- Record supported browsers and versions, specification status, runtime and product tests, Web Platform Tests where relevant, fallbacks, skipped engines, draft dependencies, and proof limits.
- Treat HTML and Fetch as Living Standards and Service Workers, Page Visibility, CSP, cookie drafts, storage, BFCache, scheduling, and connection behavior within their current maturity and engine limits.
- Specification presence, WPT coverage, one compatibility table, or one engine does not prove deployed product support.
- Do not infer exact layer promotion, GPU behavior, framework behavior, accessibility outcome, or authorization from platform evidence.

Return current evidence, validation plan, unsupported scope, proof limits, and residual risk.
