# Implementation Result

Use this optional handoff when another agent or consumer needs the result. Ordinary work can report the same relevant facts concisely without a formal artifact.

- What changed and which owner/consumer it affects.
- Current changed paths or exact change content when needed by a reviewer or integrator.
- Checks actually run after the final material edit, their results, and any skipped, unavailable, flaky, retried, or partial evidence.
- Material unresolved issues, residual risk, and proof limits.

A later material edit invalidates earlier validation for the affected behavior. Do not claim completion from stale checks or invented evidence. Independent review is optional unless explicitly requested or justified by a concrete semantic question that local checks cannot adequately resolve.

Use no daemon, database, private evidence storage, runtime task state engine, or hidden protocol record.
