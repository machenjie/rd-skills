# Review Result

Use only for an independent review requested by the user or justified by current evidence. File count, edit count, task boundaries, or completion do not themselves require review.

For each material finding give the concrete defect, source evidence, reachable failure mechanism, and required action. Identify the actual reviewed scope and any missing source or validation; no mandatory matrix, canonical finding ID, signature, fingerprint, or round metadata.

Review the current actual diff and relevant source, or the requested artifact. A summary or digest cannot replace its content. When implementation changes, refresh validation after the last material edit. Report blockers separately from adjacent optional improvements.

Resolve a finding directly in the existing implementation direction unless new evidence invalidates an important decision. Re-review only for a new material question or an unresolved required judgment; ordinary repair plus fresh targeted validation does not automatically restart review.
