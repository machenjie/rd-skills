# Data, Keychain, and Extension Implementation and Review Evidence

Load this Reference only after the accepted data, key, and extension
`decision-record` must be implemented or reviewed.

## Required Decision Input

Use the carried data inventory, storage/key owner, protection/access-group rule,
shared schema, and coordination decision. Stop when its account or target scope
is missing or stale.

## Implementation and Review Evidence

- Verify effective file protection and exact app/extension entitlements instead
  of assuming source defaults.
- Exercise device lock, missing or invalid key, account switch, partial
  migration, extension termination, corrupt data, mismatched entitlement, and
  concurrent access.

## Required Record

Return migration/recovery evidence, target and protection scope, unavailable
end-to-end proof, proof limits, and residual risk.
