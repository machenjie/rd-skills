# UI, Form-Factor, and Accessibility Implementation and Review Evidence

Load this Reference only after the accepted UI/form-factor
`selected-approach` must be implemented or reviewed.

## Required Decision Input

Use the carried framework/state owner, bridge boundary, supported form factors,
and accessibility delta. Stop when the decision omits a changed platform path.

## Implementation and Review Evidence

- Exercise compact and regular layouts, rotation, multitasking,
  keyboard/pointer input, multiple scenes, and changed iPhone/iPad navigation.
- Verify semantic identity, reading/focus order, actions, announcements,
  VoiceOver navigation, and Dynamic Type at supported content sizes.
- Inspect the rendered platform behavior; shared source alone is insufficient.

## Required Record

Return the tested iPhone/iPad matrix, accessibility evidence, device/OS scope,
unavailable assistive-technology proof, proof limits, and residual risk.
