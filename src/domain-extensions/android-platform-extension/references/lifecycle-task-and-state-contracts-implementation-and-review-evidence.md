# Lifecycle, Task, and State Implementation and Review Evidence

Load this Reference only after the accepted lifecycle/task `decision-record`
must be implemented or reviewed.

## Evidence

- Recreate the Activity without killing the process, then restore after system
  process death with the prior task or entry Intent.
- Exercise back, task removal, and relaunch; reject stale account or obsolete
  navigation state without assuming identical callbacks.

## Required Record

Return recurrence proof, tested API/device scope, unavailable OEM paths, proof
limits, and residual risk.
