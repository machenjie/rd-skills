# Special Form-Factor Boundary Implementation and Review Evidence

Load this Reference only after the accepted form-factor `boundary-decision`
must be implemented or reviewed.

## Evidence

- For Android TV, verify remote/focus, large-distance UI, playback, manifest,
  and representative-device obligations.
- For Wear OS, verify watch interaction, power, connectivity, lifecycle,
  packaging, and representative-device obligations.
- For Android Automotive, verify the exact car surface, parked/driving rules,
  app category, distraction controls, and compatible-vehicle evidence.

## Required Record

Return one row per form factor with artifact scope, exercised devices,
unavailable evidence, non-inferences, proof limits, and risk.
