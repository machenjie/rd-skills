# Storage and Keystore Implementation and Review Evidence

Load this Reference only after the accepted data/key `decision-record` must be
implemented or reviewed.

## Evidence

- Exercise missing, invalidated, rotated, and authentication-gated keys.
- Exercise restore on another device, upgrade/downgrade, account switch,
  partial migration, low storage, and corrupt records.
- Prove deletion removes all owned copies without deleting another account's
  data.

## Required Record

Return migration/recovery evidence, tested API/device scope, proof limits, and
residual risk.
