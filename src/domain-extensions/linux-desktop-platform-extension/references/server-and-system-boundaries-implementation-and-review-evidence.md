# Server and System Boundary Implementation and Review Evidence

Load this Reference only after the accepted Linux server/system owner boundary
requires implementation or review evidence.

## Required Decision Input

- Consume the accepted Professional/Foundation/Domain composition and target
  boundary. This Reference never selects or changes the route.

## Implementation and Review Evidence

- For an accepted Linux server or daemon owner, record the Professional and
  Linux systems Foundation and prove Linux Desktop remains rejected.
- For an accepted graphical client plus companion daemon boundary, record the
  protocol, identity, lifecycle, install/update behavior, failure isolation,
  validation split, and separate evidence.

## Required Record

Return an evidence record, proof limit, and validation plan for accepted-owner
protocol, lifecycle, installation, validation, and boundary behavior.
