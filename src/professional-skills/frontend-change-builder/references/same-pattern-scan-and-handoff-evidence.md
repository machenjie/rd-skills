# Same-Pattern Scan and Handoff Evidence

Use this evidence-pattern Reference only for the named same-pattern-scan-and-handoff-evidence decision.

## Evidence Contract

- For a bug fix, search sibling components, hooks, stores, validators, API clients, and tests for the same state, error, accessibility, security, or placement pattern.
- Record searched paths, related occurrences, inclusion or exclusion reasons, and why the complete repair is local or broad.
- Bind a similar-pattern absence claim to recorded search evidence.
- Treat design-system wrappers, generated clients, shared hooks, and global stores as higher-blast-radius surfaces and return unresolved architecture or security ownership.
- Record permission or sandbox, test scope, rollback, and redaction for browser, app, account, API, storage, production-like, or connector actions.

Close with inspected boundaries, placement rationale, state and failure map, accessibility and security evidence, current tests and artifacts, proof limits, residual risk, and the next owner.
